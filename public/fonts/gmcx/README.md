# GMCX typography

The reference site https://gmcx.bt/ uses **Lora** headings and **Roboto** body text. These locally bundled variable fonts come from the official Google Fonts sources, so the museum kiosk does not depend on external font servers.

- https://github.com/google/fonts/tree/main/ofl/lora
- https://github.com/google/fonts/tree/main/ofl/roboto

Their SIL Open Font License notices are included alongside the font files. No GMCX website scripts, analytics, navigation or visitor information is bundled.
