# Morning Sanctuary material sources

Photographic 1K PBR texture sets from **Poly Haven**, licensed CC0-1.0:

- [Bark Brown 01](https://polyhaven.com/a/bark_brown_01)
- [Grass Ground](https://polyhaven.com/a/grass_ground)
- [Rock Boulder Dry](https://polyhaven.com/a/rock_boulder_dry)

[Poly Haven asset licence](https://polyhaven.com/license). `manifest.json` records original URLs, byte lengths and SHA-256 checksums. Maps are bundled locally, never fetched from an external provider by the kiosk. Colour maps are sRGB; OpenGL normal and roughness maps use linear/non-colour data. Leaf veins and background foliage masks are deterministic procedural textures authored in this project. No flat landscape photograph or generated background replaces the 3D terrain.
