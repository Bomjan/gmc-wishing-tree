# Wall of Us

`Wall.tsx` handles capture, default sizing, customisation, submission and Undo, wall browsing and name search. `tracing/HandCapture.tsx` fits a stylised hand from five touch contacts using geometry in `paint.ts`, which also renders deterministic paint. The wall loads lazily through `src/app/Router.tsx`. See [the handoff](../../../docs/handprint-wall-handoff.md) for setup and touchscreen requirements.
